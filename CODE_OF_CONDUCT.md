# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be kind, assume good intent, and keep discussions about the work.

Questions and ideas belong in [Discussions](https://github.com/churnast/hermes-telegram-stickers/discussions).
To report unacceptable behaviour, use **Report content** in the menu of the comment, issue or discussion
in question. For something you would rather not post at all, write to the maintainer through the private
form on the [Security tab](https://github.com/churnast/hermes-telegram-stickers/security/advisories/new)
and start the title with "Conduct".
